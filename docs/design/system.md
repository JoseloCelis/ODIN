# Sistema de Diseño ODIN

Basado en la implementación actual de GTK4 + Libadwaita.

## Colores (tokens)
- bg-base: #1a1a1a (fondo ventana principal, Adwaita dark)
- surface: #2e2e2e (paneles laterales, botones)
- accent: #3584e4 (color principal de acción, Adwaita blue)
- text-primary: #ffffff
- text-secondary: #9a9a9a

## Tipografía
- Inter (sistema Libadwaita), tamaño base 10pt (13px), pesos 400 y 600.

## Espaciado
- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px

## Componentes
- Paneles laterales con Adw.ToolbarView y Adw.NavigationPage.
- Botones de acción tipo Adw.Button.
